# Анатомия атласы

Қазақ тіліндегі интерактивті анатомия атласы — 8-сынып «Биология» оқулығына (Атамұра, 2018) негізделген веб-қосымша.

**Сайт:** https://nazabekkalikyzy-max.github.io/Nazerke-Smagul/

## Мүмкіндіктері
- **3D модельдер:** жүрек, ми, тістер, көз — әр бөлігі қазақша және латынша атауымен; 3D тапсырма режимі.
- **Тапсырмалар:** 34 тақырып бойынша теориялық материал, терминдер, 429 сұрақ-жауап (флеш-карта, тест, база).
- **Қосымша бекіту тапсырмалары:** бөлімдер бойынша аралас тест.
- **Зертханалық жұмыстар:** 11 жұмыс, нәтижелерді енгізгенде сайт қорытынды шығарады.
- Телефонға қосымша ретінде орнатуға болады (PWA), бір рет ашқаннан кейін интернетсіз де жұмыс істейді.

Смағұл Назерке, Абай университеті, 1-курс магистранты.
